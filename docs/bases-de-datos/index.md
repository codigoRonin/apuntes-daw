## Cómo trabajar con estos apuntes

Cada unidad incluye un juego de datos para que ejecutes **todos** los ejemplos en tu SGBD. En este módulo no basta con leer: cada consulta hay que ejecutarla, romperla y arreglarla. Los ejercicios de cada apartado se entregan según lo indicado en clase; la actividad evaluativa final se entrega como script SQL en tu repositorio.
