# Recursos transversales

**Ciclo DAW · IES Río Arba · Curso 2026-27**

Aquí están los materiales que no pertenecen a ninguna unidad concreta: guías para montar tu entorno de trabajo, normas comunes de entrega y las reglas con las que se valora la defensa de tus trabajos. Se consultan cuando hacen falta, y cada uno indica al principio a qué módulo sirve.

## Apartado 1. Qué hay y para qué sirve

| Recurso | Módulo | Para qué |
|---|---|---|
| [Entorno de trabajo: VS Code para PHP](entorno-vscode-php.md) | Desarrollo Web en Entorno Servidor | Montar una sola vez el editor con el que trabajarás todo el módulo |
| [Entorno de trabajo: VS Code para Python](entorno-vscode-python.md) | Big Data e Inteligencia Artificial | Añadir al mismo editor lo necesario para Python y los cuadernos de Jupyter |

| [Estándar de estilo SQL](estandar-estilo-sql.md) | Bases de Datos | Cómo se escribe, se entrega y se corrige el SQL de todas las entregas |
| [Rúbrica de defensa y de verificación de autoría](rubrica-defensa.md) | Los tres módulos | Cómo se valora la defensa de cada entrega evaluable y qué ocurre si no se supera |

## Apartado 2. Cómo usarlos

1. **Los de entorno, al empezar el módulo.** Se siguen una vez, de principio a fin, y después solo se vuelve a ellos si algo deja de funcionar.
2. **Los de entrega, antes de entregar.** La guía de draw.io y el estándar de SQL dicen cómo tiene que llegar tu trabajo para que se pueda corregir; repásalos antes de cada entrega de ese tipo.
3. **La rúbrica de defensa, antes de cada defensa.** Te dice qué se te va a pedir en esos minutos y cómo prepararte.

Si un recurso y una unidad parecen decir cosas distintas, manda la unidad, y conviene que lo comentes en clase para corregirlo.
